Erlang/Elixir TCP client for [Event Store](http://geteventstore.com/).

This version is tested with EventStore 5.0.11 and 21.10.5, Elixir 1.18 - 1.20 and Erlang/OTP 25 - 29.
It requires Elixir 1.16 or later.

EventStore messages (`Extreme.Messages.*`) are generated by [protobuf](https://hex.pm/packages/protobuf)
from `include/event_store.proto`; regenerate them with `scripts/gen_messages.sh`.
